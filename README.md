🌸 DSA Visualiser

🌐 Live Website: https://pragya-dsa-visualizer.netlify.app/

A minimal, pastel-themed interactive DSA Visualiser designed to make algorithms feel simple, smooth, and visually intuitive. Built with a clean UI and calming color palette, this project focuses on both educational clarity and aesthetic design.


✨ Features

📊 Sorting Visualisations

Bubble Sort

Selection Sort

Insertion Sort

Merge Sort

Quick Sort

🔎 Searching Algorithms

Linear Search

Binary Search

🎛 Interactive Controls

Start / Pause / Reset

Speed Control (Slow / Medium / Fast)

Custom Array Input


🎨 Pastel Minimal UI

Soft color-coded comparisons

Rounded cards & clean layout

Smooth animations

📱 Fully Responsive Design



🛠 Tech Stack

HTML

CSS

JavaScript (Algorithm Logic + Animation Handling)


🚀 How It Works

Arrays are represented as animated vertical bars.
Each algorithm updates bar heights and colors in real time to demonstrate:

Comparisons

Swaps

Sorted elements

Search results

Speed control dynamically adjusts animation delay.
